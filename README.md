**AETHER SUITE** — модульный оптимизатор, системный монитор и кастомизатор для Windows 10/11 на Python (PySide6). Объединяет в себе безопасные твики реестра с откатом, готовые пресеты под разные задачи, бенчмарк, HUD-оверлей, глобальные эффекты курсора и живые обои.

---

## Основные возможности

### Мониторинг и диагностика
* **Статистика ПК в реальном времени:** загрузка CPU, RAM, диска, сети, аптайм и асинхронный мониторинг NVIDIA GPU (`nvidia-smi`) без фризов интерфейса.
* **Живые спарклайны и цветовые статусы:** мини-графики нагрузки за последние 60 секунд и динамическая подсветка (зелёный → жёлтый → красный).
* **Бенчмарк с историей:** многопоточный и однопоточный тест CPU, оценка RAM, скорость записи/чтения диска и сохранение результатов для сравнения «до/после».
* **Осмотр сессий и процессов:** журнал включений/перезагрузок из Windows Event Log, активные сетевые соединения, поиск и завершение процессов с защитой критических системных процессов.
* **Экспорт отчёта:** сохранение характеристик ПК и результатов бенчмарка в готовый HTML-файл.

### Оптимизация и безопасность
* **6 готовых шаблонов:** *Гейминг (Max FPS)*, *Программирование (Dev)*, *Многозадачность*, *Стрим / Запись*, *Тихий / Минимализм* и *Сброс к стандарту* — с окном предпросмотра изменений.
* **Автобэкап и откат:** перед применением шаблона или ручных твиков текущие настройки сохраняются в JSON, их можно откатить в один клик. Есть создание системной точки восстановления Windows.
* **Ручные твики с чтением реестра:** тумблеры автоматически подтягивают реальное состояние системы (схемы питания, GameDVR, телеметрия, Raw Input мыши, тёмная тема, панель задач Win 11, расширения файлов и др.). Поддержка импорта/экспорта своих пресетов в JSON.
* **Автозагрузка и службы:** управление автозапуском (`HKCU`/`HKLM`) и безопасным списком служб Windows (`SysMain`, `DiagTrack`, Xbox и др.).
* **Диск и сеть:** переключение DNS (Cloudflare / Google / DHCP), сброс DNS и Winsock, пинг, очистка Temp (с предварительным подсчётом размера), очистка корзины и поиск крупных файлов (> 50 МБ).

### Визуальная кастомизация и оверлеи
* **HUD-оверлей:** компактный мини-виджет с CPU/RAM/GPU/сетью, режимами *Always On Top*, *Click-Through* (сквозной клик) и настройкой прозрачности.
* **Курсор и глобальные эффекты:** изменение размера и схем курсора, загрузка своих `.cur`/`.ani` файлов, **волна при клике** и **след за курсором** (*Неоновый хвост*, *Партиклы*, *Точки*, *Свечение*, *RGB-режим*) поверх всех окон.
* **Живые обои:** процедурные анимации (*Созвездие*, *Северное сияние*, *Matrix*) позади иконок рабочего стола.
* **Виджеты:** *Keystroke OSD* (показ нажатых клавиш и комбинаций) и стеклянные часы в стиле *Liquid Glass*.
* **Интерфейс:** Frameless-окно с кастомной шапкой, HiDPI SVG-иконки, плавные анимации, сворачиваемый сайдбар, системный трей и темы оформления (*Crimson Dark*, *Monochrome*, *Liquid Glass* + выбор своего акцента).

## Структура проекта

```text
aether_suite/
├── main.py                # Главное окно, навигация, трей и сборка страниц
├── core/
│   ├── engine.py          # Реестр, твики, бэкап/откат, автозагрузка, службы, сеть
│   ├── workers.py         # Потоки: GPU-мониторинг, бенчмарк, Event Log, анализ диска
│   └── cursor.py          # Управление системным курсором Windows (WinAPI)
└── ui/
    ├── styles.py          # Генератор тем оформления и HiDPI SVG-иконки
    ├── widgets.py         # Спарклайны, ToggleSwitch, анимации прогресс-баров и тостов
    ├── hud.py             # Мини-HUD оверлей
    ├── click_fx.py        # Глобальные волны кликов и след за курсором
    ├── live_wallpaper.py  # Живые обои (интеграция в Progman / WorkerW)
    ├── keystroke_osd.py   # Оверлей нажатий клавиш
    └── desktop_widgets.py # Виджет часов Liquid Glass
